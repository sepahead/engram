# Engram Neural Modeling Labs

Auditable computational neuroscience workflows with NEST.

Engram connects reviewed model evidence, simulation inputs, and recorded results.
This public repository is a placeholder. Executable source remains private pending publication.

An optional [NCP](https://github.com/sepahead/NCP) integration connects NEST to [CREBAIN](https://github.com/sepahead/crebain) sensor simulations.
A bounded native experiment completed eight neural steps and 24 body ticks.
All 64 count and rate comparisons matched direct NEST execution.
The experiment used explicit network and scene inputs.

These results do not establish arbitrary-paper reproduction, calibrated inference, physical validation, or real-time operation.
NCP v1 qualification remains in progress.

[Prisoma](https://github.com/sepahead/prisoma) provides separate experiment recording and model evaluation.
